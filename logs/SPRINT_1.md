# Sprint 1 작업 로그

## 프로젝트

- 게임명: 오늘도 던전 영업합니다
- 영문명: Dungeon as Usual
- 엔진: Godot 4.7.2
- 언어: GDScript
- 플랫폼: PC
- 작업 범위: 2D 평면 던전 경영·관전 프로토타입
- 상태: Sprint 1 핵심 플레이 루프 구현 완료

## 릴리즈 요약

플레이어가 직접 던전을 설계하고, 용사가 던전 전체 구조를 모르는 상태에서 자동 탐험하는 핵심 관전 루프를 구현했다.

구현된 흐름:

```text
던전 편집
→ 던전 영업 시작
→ 용사 자동 탐험
→ 함정 및 몬스터 조우
→ 용사 사망 시 에너지 획득 및 새 용사 입장
→ 보물 획득
→ 결과 화면
→ 던전 수정
```

## 구현 기능

### 던전 편집

- 기본 Entrance 자동 생성
- 빈 방, 가시 함정, 슬라임, 보스, 보물 방 추가
- 방 선택 및 삭제
- 방 연결 생성
- 방 연결 삭제
- Entrance에서 Treasure까지 경로 유효성 검사
- 클릭 배치 방식의 2D Node Graph 편집

### 자동 탐험

- 용사 HP 20, 공격력 4
- 방문 기록과 탐험 중 발견한 연결 정보만 사용
- 미방문 방 무작위 선택
- 방문 가능한 방이 없으면 Backtracking
- 현재 용사 위치 시각화
- 방문하지 않은 방 어둡게 표시

### 방 효과 및 전투

- 가시 함정: 입장 시 피해 5
- 슬라임: HP 8, 공격력 2
- 보스: HP 20, 공격력 4
- 짧은 간격의 자동 턴 전투
- 현재 Dungeon Run 동안 처치한 몬스터 상태 유지
- 보물 획득 시 Dungeon Run 종료

### 용사 생명주기

- 용사 사망 시 에너지 10 획득
- 사망한 용사 수 집계
- 약 1초 후 새 용사 입구 생성
- 새 용사는 이전 용사의 탐험 정보를 공유하지 않음

### UI 및 관전 기능

- 편집 모드와 영업 모드 표시
- 에너지, 입장 수, 사망 수 표시
- 현재 용사 체력과 행동 상태 표시
- 이동, 함정, 전투, 사망, 보물 획득 메시지 표시
- 진행 속도 x1, x2, x4
- 던전 공략 완료 결과 화면
- 던전 수정 화면으로 돌아가기
- 버튼과 상태 메시지 한글화

## 실행 방법

1. Godot 4.7.2를 실행한다.
2. 프로젝트 관리자에서 `D:\practice\Dungeon\project.godot`를 가져온다.
3. 프로젝트를 연다.
4. `F5` 또는 오른쪽 위 실행 버튼을 누른다.

## 간단한 플레이 테스트

1. `빈 방 추가`, `가시 함정 추가`, `슬라임 추가`, `보스 추가`, `보물 추가`로 방을 배치한다.
2. `방 연결`을 누르고 두 방을 차례로 클릭한다.
3. 입구에서 보물까지 연결한다.
4. `던전 영업 시작`을 누른다.
5. 용사의 탐험, 전투, 사망, 재입장, 보물 획득을 관찰한다.
6. 결과 화면에서 `던전 수정하기`를 눌러 편집 모드로 돌아간다.

## 알려진 한계

- Room은 드래그 이동이 아닌 클릭 배치 방식이다.
- 그래픽, 사운드, 애니메이션은 프로토타입 수준이다.
- 저장 및 불러오기를 지원하지 않는다.
- Godot 4.7.2에서 사용하도록 작성되었으며, 다른 버전에서의 동작은 별도 확인이 필요하다.
- Sprint 2 이후 기능은 구현하지 않았다.
