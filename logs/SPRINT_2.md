# Sprint 2 개발 로그

## DEPTH 메뉴 UI 및 편집 기능

- DEPTH1을 `방`, `장애물`, `몬스터`, `통로`, `보기` 메뉴로 분리했다.
- DEPTH2 내용은 선택한 DEPTH1에 따라 표시되며, 버튼 묶음이 아닌 메뉴 행 UI로 구성했다.
- 메뉴 선택 상태, DEPTH2 내용 표시 상태, 실제 마우스 작업 상태를 분리했다.
- 단일 기능은 한 번 실행 후 실제 작업만 해제하고, 메뉴와 DEPTH2 내용은 유지한다.
- 기본 상태는 `보기`이며, `보기` 선택 시 DEPTH1은 보기로 유지하고 DEPTH2 내용과 실제 작업만 초기화한다.
- 방의 단일/연속 그리기, 입구방·보물방 설정, 단일/연속 삭제를 추가했다.
- 장애물·몬스터는 종류를 선택한 뒤 방을 클릭해 배치한다.
- 통로는 단일/연속 생성 및 삭제를 지원한다.
- 하단에 `보물방 0/1`, `입구방 0/1`, `던전 오픈` 영역을 분리했다.
- 보물방은 정확히 1개, 입구방은 정확히 1개일 때만 던전을 열 수 있다.
- 작업별 마우스 커서로 활성 기능과 보기 상태를 구분한다.
- 보기 상태에서 빈 맵 드래그는 맵 이동, Room 드래그는 Room 이동으로 구분한다.
- 통로가 연결된 Room은 보기 상태에서 이동·크기 조절을 잠근다.
- 마진 칸을 실제 사각형 단위로 판정해 모서리·경계 클릭 오류를 수정했다.
- 첫 번째 마진은 임의의 방에서 선택할 수 있고, 두 번째는 다른 방의 마주 보는 마진만 허용한다.
- 대각선 마진과 기존 통로 중복 연결을 차단한다.
