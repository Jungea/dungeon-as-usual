# Sprint 3 개발 로그

## 진행 정보·분석·미니맵 1차 구현

- 영업 진행 중 오른쪽 분석 패널에 용사 HP, 행동, 최근 이벤트를 표시한다.
- 방 번호, 피해량, 효과, 이벤트 후 HP를 이벤트 로그에 기록한다.
- 함정·몬스터별 누적 피해량과 최대 단일 피해량을 집계한다.
- 용사별 사망 원인과 마지막 피해 요소를 기록한다.
- 던전 종료 결과에 사망 원인, 최다 피해 요소, 마지막 일격 횟수를 표시한다.
- 용사 스택은 던전 재오픈 시에도 누적한다.
- 편집 모드에서 Room 이름을 입력·저장할 수 있다.
- 던전 오픈 후 맵에 Room 번호를 표시하고, 이름이 있으면 번호와 함께 표시한다.
- 우측 상단에 반투명 미니맵을 표시한다.
- 미니맵에 Room, 통로, 입구방·보물방, 현재 용사 위치를 표시한다.
- 미니맵 클릭으로 본 맵을 해당 위치로 이동한다.
- 영업 중 방을 클릭하면 선택 방의 전투·요소·HP 상태를 분석 패널에서 확인한다.
- 현재 용사가 전투 중이면 방 위에 `전투 중` 표시와 펄스 효과를 표시한다.
- x1 기본 속도는 이동·전투 턴 간격을 늘려 턴제 진행이 보이도록 조정했다.
